## Ejecución y Reproducibilidad

### 1. Ejecución en la Nube (Google Colab)
Cada notebook cuenta con un botón interactivo **Open In Colab** en la tabla anterior y al inicio de cada archivo. Al pulsar el botón, el entorno se inicializa automáticamente y descargará cualquier conjunto de datos requerido directamente desde este repositorio.

### 2. Ejecución Local

Para clonar y reproducir los notebooks en tu máquina local:

```bash
# Clonar el repositorio
git clone https://github.com/fabianalexisbernabecruz-code/portafolio-actuaria-unam.git
cd portafolio-actuaria-unam

# Crear entorno virtual (opcional pero recomendado)
python -m venv .venv
source .venv/bin/activate  # En Linux/macOS
# .venv\Scripts\activate   # En Windows

# Instalar dependencias
pip install -r requirements.txt

# Iniciar Jupyter Lab o Notebook
jupyter lab
```
